# Samiya & Suhin Proposal Website

A mobile-first romantic proposal website with a professional burger menu.

## Menu sections

- Home
- Our Story
- Photo Gallery
- Reasons I Love You
- Special Message
- Our Memories
- Proposal
- Contact Suhin

## Customize

Open `index.html` in a code editor and replace:

- Photo gallery placeholders
- Story and memory text
- Suhin's example phone number
- Suhin's example email address

## Run

Open `index.html` in a modern browser.

## Publish

Upload this folder to Netlify, Vercel, GitHub Pages, or another static host.
